# Amharic OCR Frontend

This is a minimal React + Vite scaffold for the Amharic OCR project.

Quick start

1. Install dependencies

```bash
cd frontend
npm install
```

2. Run dev server

```bash
npm run dev
```

3. Build for production (outputs to `assets/frontend`)

```bash
npm run build
```

Notes
- The Vite build output is configured to `assets/frontend` so the backend can serve static files from the existing `assets/` folder.
